FacePay

FacePay is a web-based face recognition system that uses the DeepFace algorithm to detect and verify faces.
It uses a webcam to capture an image and compares it with a registered face stored as a Base64 string.
The project is developed using the Python Django Framework.

Features

Face recognition using the DeepFace algorithm

Webcam capture for real-time face detection

Face comparison against registered Base64 images

Web-based implementation using Django

Requirements

Python 3

Webcam (for face capture)
